# commit-kind

A small Python CLI and library that classifies git commit messages by type (`feat`, `fix`, `docs`,
`refactor`, `test`, `chore`) with a transparent, rule-based classifier. Every prediction names the
rule that produced it.

## Status

Milestone 1 is in progress. The CLI is not usable yet beyond `--version`.

## Requirements

Python >= 3.10. Development tools (ruff, mypy, pytest) come from the `dev` extra.

## Quality gate

```
./scripts/check.sh
```

Runs ruff, ruff format, mypy (strict) and pytest, and exits non-zero if any step fails. Set
`PYTHON=` to choose the interpreter.

## Dataset

`data/commits.jsonl` holds 360 synthetic commit messages (60 per label, split 50/50 into dev and test),
generated by this project with a fixed seed. No real repository data is used.

```
python3 scripts/generate_dataset.py --seed 20261025 --out data/commits.jsonl
```

Synthetic, generated by this project; tune on dev only.

## Eval

`python3 -m commit_kind eval` scores the test split on accuracy, macro-F1, min recall and misleading-slice accuracy.
Three negative controls (majority class, keyword spam, random) must fail every metric; a configured classifier
must pass all of them and not fall below `evals/baseline.json`. Exit codes: 0 pass, 1 gate failed, 2 usage,
3 bad or missing config, dataset or baseline. The thresholds in `evals/config.json` were approved by the
owner on 2026-10-25. Tune on dev with `--split dev --show-errors`; `--write-baseline --block B<n>` rewrites the baseline.

## Try it

```
PYTHONPATH=src python3 -m commit_kind --version
```
